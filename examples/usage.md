# 用例样例 — icp-edi-helper

> 三个典型场景：标准评估 / 跨省咨询 / 异常输入
> 配合 SKILL.md 5 秒决策树 + AGENTS.md 协作规则使用

---

## 用例 1：标准评估（有企业名称）

### 输入

> 加盟商："我有个客户叫'杭州某某科技有限公司'，做的是小程序商城，用户要付费才能用，帮我看下能不能办。"

### Agent 加载路径

1. SKILL.md → 命中"给企业名称/统一社会信用代码"决策点
2. 调用 `scripts/query_company.py "杭州某某科技有限公司"`
3. 输出结果对照 `references/overview.md` 第三条硬性条件

### 期望输出

```
✅ 评估结果：可办 ICP 许可证

📋 自动评估项（API 已查）：
- 注册资本：100 万 ✅
- 公司类型：有限责任公司 ✅
- 经营范围：含"增值电信业务" ✅
- 登记状态：存续 ✅
- 外资情况：无 ✅

📋 需加盟商追问 4 项：
- 3 名员工社保（连续多久？）
- 域名是否在公司名下
- 已完成 ICP 备案？
- 网站是否可访问

💬 话术建议：
"您这个业务需要办 ICP 许可证，是国家硬性要求。我用工具查了下，您公司
基本条件都满足。剩下 4 项咱们一项项过一下：员工社保交了多久、域名是
不是您名下、ICP 备案做了没、网站能不能打开。"

⏭️ 下一步：参考 references/overview.md 第三条 + references/templates/icp-templates.md
```

### 校验点

- [x] 没问用户"做什么业务"（用户已说小程序付费）
- [x] 没问"哪个省"（公司名称已含）
- [x] 调用了 API，不是干问
- [x] 给加盟商话术而非给客户

## 用例 2：跨省咨询（无企业名称）

### 输入

> 加盟商："客户在广东和江苏都有公司，做电商平台让商家入驻，哪边办 EDI 比较快？"

### Agent 加载路径

1. SKILL.md → 命中"31 省差异 / 哪家最快"决策点
2. 读 `references/province-comparison.md`（EDI 部分）
3. 按需读 `references/provinces/guangdong.md` 和 `references/provinces/jiangsu.md`

### 期望输出

```
📊 广东 vs 江苏 EDI 许可证对比

| 维度 | 广东 | 江苏 |
|------|------|------|
| 办结时限 | 60 工作日 | 45 工作日 |
| 特殊材料 | 公司章程 + 网站截图 + 服务器接入协议 | 省内 3 员工社保 |
| 外资 | 需走审批 | 需走审批 |
| 难度 | 较严 | 中等 |

💡 建议：单看速度选江苏，但客户若主业务在广东，监管便利性更重要。
     建议先确认客户主体公司选在哪边。

⏭️ 详情：references/province-comparison.md
```

### 校验点

- [x] 没强制要求用户提供公司名称
- [x] 主动读跨省差异文件
- [x] 给加盟商决策建议（不是给客户答案）

---

## 用例 3：异常输入（信息不足）

### 输入

> 加盟商："客户要办证，帮我看看。"

### Agent 加载路径

1. SKILL.md 决策树 → 无任何明确命中
2. 按 AGENTS.md 2.1 "必须先澄清"清单，识别缺 4 项

### 期望输出

```
🤔 还需要 4 个信息才能评估：

1. 客户做什么生意？（网站/小程序/平台/APP/商城...）
2. 业务模式？（自己卖货/用户付费/商家入驻/分类信息...）
3. 客户公司名称或统一社会信用代码？（有的话可以一键查工商信息）
4. 客户公司在哪个省？

💡 经验：
- 业务类型决定办 ICP 还是 EDI
- 有企业名称可用 API 自动评估 5 项硬性条件
- 不同省材料和办结时限差异很大

⏭️ 拿到信息后回到 SKILL.md 第 0 节"AI 5 秒决策树"
```

### 校验点

- [x] 没有"基于合理假设"直接给空泛建议
- [x] 没有问超过 4 个问题
- [x] 解释了为什么需要这些信息（让加盟商理解）

## 反例（不应输出）

### ❌ 反例 1：把 references 内容大段复制

```
# 错误示范
根据 references/overview.md 第三条规定，ICP 许可证的硬性条件包括：
1. 注册资本不低于 100 万元人民币
2. 公司性质必须是内资有限责任公司
...（以下省略 800 字）
```

✅ **正确做法**：`见 references/overview.md 第三条`

### ❌ 反例 2：让客户直接看到加盟商话术

```
# 错误示范（输出给"客户"身份的用户）
"您需要办一个 ICP 许可证。注册资本要 100 万...近三年无违法..."
```

✅ **正确做法**：识别用户身份是加盟商时，给"您对客户说..."的话术模板。

### ❌ 反例 3：硬说"各省都一样"

```
# 错误示范
"全国统一：办 ICP 许可证需要 60 个工作日。"
```

✅ **正确做法**：注明"全国 60 工作日是上限，各省差异大，见 references/province-comparison.md"。
