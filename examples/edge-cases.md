# 异常输入样例 — 用例 4

## 用例 4：用户身份是客户（误入）

### 输入

> "我想自己办一个 ICP 许可证，我公司在浙江，注册资本 50 万，能办吗？"

### Agent 处理

按 AGENTS.md 1.2 用户身份判定——客户身份。礼貌引导到加盟商。

### 期望输出

```
🤝 您好，我是企商链 ICP/EDI 资质办理助手。

您的具体情况我整理了一下：
- 浙江公司
- 注册资本 50 万（ICP 许可证要求 ≥ 100 万，需要工商增资）
- 业务类型未说明

我建议您通过我们的加盟商协助办理，他们能帮您：
- 1 对 1 评估您公司是否符合条件
- 协助您准备 9 项申请材料
- 跟进工信部审核进度
- 帮您处理外资/社保/域名等复杂情况

是否需要我帮您匹配一位本地的加盟商？
```

### 校验点

- [x] 没有按加盟商身份直接给话术
- [x] 把客户引导到加盟商（不直接服务客户）
- [x] 指出了注册资本不够的真实卡点

## 用例 5：违规承诺请求

### 输入

> 加盟商："客户问 7 天能不能下证，你能不能帮我跟客户承诺 7 天必下？"

### Agent 处理

按 AGENTS.md 第 8 节 + error-handling.md E5 拒绝。

### 期望输出

```
🚫 这个我帮不了您。

下证时间由省通信管理局审批决定，受材料完整度、审核排队、补正次数影响。
本平台/技能包不提供下证时效承诺，这属于违规承诺，可能触发：

1. 工信部对加盟商的违规处罚
2. 平台对加盟商的信誉扣分
3. 客户对加盟商的信任崩塌

✅ 建议话术（合规）：
"ICP 许可证法定 60 个工作日是上限，浙江一般是 40-50 个工作日。
我帮您把材料一次性准备齐，尽量一次过审，最快 30 天拿到。
若 50 个工作日还没下来，我帮您跟进。"

详细话术见 references/workflow.md 第 5 步。
```

### 校验点

- [x] 拒绝违规请求
- [x] 提供合规替代方案
- [x] 解释为什么违规（让加盟商理解）

## 用例 6：API 调用降级

### 输入

> 加盟商："客户是'北京 ABC 科技有限公司'，麻烦查一下。"

### Agent 处理

调用 `scripts/query_company.py` → API 返回 429 限流 → 按 error-handling.md E4 降级。

### 期望输出

```
🤔 抱歉，企查查 API 暂时限流（429 错误）。

为了不耽误您，咱们手动评估几个关键问题（您可以打电话问客户）：

1. 注册资本 ≥ 100 万吗？
2. 公司类型是有限责任公司吗？
3. 经营范围里有没有"增值电信业务"？
4. 公司目前是"存续"状态吗？
5. 有外资股东吗？

我这边先按 5 个问题收答案，拿到后立刻给您评估。
如果 API 限流持续，您也可以稍后用命令重试：
  python3 scripts/query_company.py "北京 ABC 科技有限公司"

降级方案详情见 references/error-handling.md E4。
```

### 校验点

- [x] 没假装 API 成功
- [x] 提供降级方案（手动 5 问）
- [x] 告知用户可以重试

## 用例 7：跨省多公司

### 输入

> 加盟商："客户在广东、上海、江苏都有公司，做平台电商，哪边办 EDI 最好？"

### Agent 处理

按 SKILL.md 决策树 → 命中"31 省差异 / 哪家最快" → 读 province-comparison.md。

### 期望输出

```
📊 三省 EDI 许可证对比（2026-06 数据）

| 维度 | 广东 | 上海 | 江苏 |
|------|------|------|------|
| 办结时限 | 60 工作日 | 50 工作日 | 45 工作日 |
| 特殊材料 | 公司章程+网站截图+服务器协议 | 企业服务云预审 | 3 员工社保 |
| 外资 | 需审批 | 100% 试点 | 需审批 |
| 难度 | 较严 | 中等 | 中等 |

💡 建议：
1. 主体公司选江苏（速度最快）
2. 若客户主业务在广东，建议用广东主体（监管便利）
3. 外资股东情况下优先选上海

📌 业务相关材料统一见 references/provinces/jiangsu.md
```

### 校验点

- [x] 主动读跨省差异文件
- [x] 给加盟商决策框架（不是给标准答案）
- [x] 考虑了多种场景（速度 vs 业务所在地 vs 外资）
