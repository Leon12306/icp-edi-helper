## 一、核心入口

| 入口 | URL |
|------|-----|
| **工信部政务服务平台** | https://ythzxfw.miit.gov.cn |
| **电信业务市场综合管理信息系统** | https://tsm.miit.gov.cn |

**通用流程（所有省都一样）：**
1. 登录 `ythzxfw.miit.gov.cn` → 注册企业账号
2. 首页点击【行政许可】→【电信业务经营许可】→【在线办理】
3. 选择业务类型：省内许可证 或 跨地区许可证
4. 选择"信息服务业务(仅限互联网信息服务)"= ICP
5. 填写申请表 + 上传材料

---

## 二、ICP许可证 vs EDI许可证 快速判断

| 你的业务 | 需要哪种 |
|---------|---------|
| 自己做电商卖货（自营） | ICP备案即可 |
| 内容付费/会员制网站 | ICP许可证 |
| 分类信息/招聘/广告平台 | ICP许可证 |
| 让商家入驻你平台卖货 | EDI许可证 |
| 在线数据处理/订单处理 | EDI许可证 |
| 企业官网（不收费） | ICP备案 |

## 三、ICP/EDI 硬性条件（全国统一）

| 条件 | 要求 |
|------|------|
| 注册资本 | ≥ 100万元（认缴即可，无需实缴） |
| 公司形式 | 有限责任公司（个体户不行） |
| 员工社保 | 3名员工近1个月社保 |
| 域名 | 在公司名下，剩余有效期≥6个月 |
| ICP备案 | 已完成（先备案后办证） |
| 网站 | 有完整功能页面可访问 |
| 内资 | 不能有外资控股（外资需走额外审批） |
| 经营范围 | 营业执照需含"增值电信业务"或"经营电信业务" |

## 四、所需材料清单（ICP通用）

1. 营业执照副本（彩色扫描件）
2. 法人身份证正反面（彩色扫描件）
3. 股东身份证或营业执照（视股东性质）
4. 域名注册证书
5. ICP备案证明
6. 3名员工社保证明
7. 业务发展可行性研究报告
8. 互联网信息安全管理制度
9. 用户服务协议（含用户协议+隐私政策）
10. 服务器托管/接入协议
11. 申请表（在线填写）

> EDI 特有材料（比 ICP 多两项）：`references/edi-knowledge.md`

## 五、办理周期 & 费用

| 项目 | 费用 |
|------|------|
| 官方收费 | **免费** |
| 代办费用 | — |
| 办理周期 | 60个工作日（约3个月） |
| 有效期 | 5年，到期前90天申请续期 |

## 六、未办理后果

根据《互联网信息服务管理办法》：
- 通信管理局责令限期改正
- 有违法所得的，没收违法所得，处违法所得3-5倍罚款
- 无违法所得或不足5万元的，处**10-100万元罚款**
- 情节严重的，**责令关闭网站**

---

## 七、年报要求

- 每年 **1-3月** 提交年报
- 通过 `tsm.miit.gov.cn` 填报
- 连续3年未年报可能列入不良名单
- 连续5年零申报可能无法续期
- 详细流程 → `references/licensing-changes.md`

## 九、跨地区（全网）vs 省内（地网）

| 类型 | 审批机构 | 注册资本 | 适用范围 |
|------|---------|---------|---------|
| 省内证 | 省通信管理局 | ≥ 100万 | 单个省/直辖市/自治区 |
| 跨地区证 | 工信部 | ≥ 1000万 | 全国范围 |
