# 资质关键词映射表

把用户口语化的描述，映射到需要的资质类型。

> **范围限定**：本映射表仅覆盖 ICP/EDI 相关资质。其他资质类型（食品、医疗、文化、出版物、人力资源、交通等）不在本 Skill 覆盖范围内。

| 用户口语 | 需要的证 | 说明 |
|---------|---------|------|
| "我做网站" | ICP备案 或 ICP许可证 | 看是否收费 |
| "我做个小程序" | ICP备案 或 ICP许可证 | 看是否收费 |
| "我网站要收用户费" | ICP许可证 | 经营性信息服务 |
| "我做会员制" | ICP许可证 | 属于内容/服务付费 |
| "我做内容付费" | ICP许可证 | 典型 ICP 场景 |
| "我做个分类信息平台" | ICP许可证 | 信息发布+收费 |
| "我让商家入驻卖货" | EDI许可证 | 第三方商家入驻 |
| "我做一个电商平台让其他人卖东西" | EDI许可证 | 典型 EDI 场景 |
| "我做在线数据处理" | EDI许可证 | 在线交易处理 |
| "我做一个二手交易平台" | EDI许可证 | C2C 交易处理 |
| "我自己卖货的官网" | ICP备案 | 自营，不收费 |
| "我企业官网不收费" | ICP备案 | 纯展示无需许可 |
