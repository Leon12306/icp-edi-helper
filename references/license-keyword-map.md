# 资质关键词映射表

把用户口语化的描述，映射到需要的资质类型。

## ICP/EDI 相关

| 用户口语 | 需要的证 |
|---------|---------|
| "我做网站" | 可能是 ICP备案 或 ICP许可证 |
| "我做个小程序" | 可能是 ICP备案 或 ICP许可证 |
| "我网站要收用户费" | ICP许可证 |
| "我做会员制" | ICP许可证 |
| "我做内容付费" | ICP许可证 |
| "我做个分类信息平台" | ICP许可证 |
| "我让商家入驻卖货" | EDI许可证 |
| "我做一个电商平台让其他人卖东西" | EDI许可证 |
| "我做在线数据处理" | EDI许可证 |
| "我做一个二手交易平台" | EDI许可证 |
| "我自己卖货的官网" | ICP备案 |
| "我企业官网不收费" | ICP备案 |

## 食品相关

| "我开奶茶店" | 食品经营许可证 |
| "我做外卖" | 食品经营许可证 |
