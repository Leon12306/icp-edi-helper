# EDI 许可证 — 完整知识库

> 数据来源：工信部官网、各省通信管理局、华为云、腾讯云等公开资料
> 更新日期：2026-06-02

---

## 📖 是什么

**EDI 许可证** = 《在线数据处理与交易处理业务经营许可证》

通俗说：如果你的平台要让**其他商家入驻卖东西**，你就需要 EDI 许可证。

> 类比：淘宝 = EDI（商家入驻）；京东自营 = 不需要 EDI（自己卖）

---

## 🔍 我需要办吗？（3 个判断问题）

**Q1：你的平台是让商家入驻，还是自己卖货？**
- 自己卖自己的商品 → 不需要 EDI
- 让别人在你平台开店卖货 → 需要 EDI

**Q2：你的平台有交易流程吗？**
- 有下单、支付、订单管理 → 需要 EDI
- 只有信息发布，没有交易功能 → 不需要 EDI

**Q3：你的业务属于在线数据处理/交易处理吗？**
- 订单处理、电子数据交换、交易数据处理 → 需要 EDI
- 只是内容展示/信息发布 → 不需要（可能需要 ICP）

**3 个问题里有 2 个"是" → 需要办 EDI 许可证。**

---

## ⚠️ 不办的后果

跟 ICP 许可证相同：
- 通信管理局责令限期改正
- 有违法所得的，没收违法所得 + 处违法所得 **3-5 倍罚款**
- 无违法所得或不足 5 万的，处 **10-100 万罚款**
- 情节严重的，**责令关闭网站**

---

## ✅ 硬性条件

EDI 的硬性条件跟 ICP 完全一样（详见 `references/overview.md` 第三条）：

| 条件 | 要求 |
|------|------|
| 注册资本 | ≥ 100 万元（认缴即可，无需实缴） |
| 公司形式 | 有限责任公司（个体户不行） |
| 员工社保 | 3 名员工近 1 个月社保 |
| 域名 | 在公司名下，剩余有效期 ≥ 6 个月 |
| ICP 备案 | 已完成 |
| 网站 | 有完整交易功能页面可访问 |
| 内资 | 不能有外资控股（外资需走额外审批） |
| 经营范围 | 营业执照需含"增值电信业务"或"经营电信业务" |

## 📝 材料模板

### 平台交易流程说明模板

```
【平台名称】交易流程说明文档

一、用户注册流程
1. 用户访问平台网址
2. 输入手机号/邮箱注册账号
3. 填写个人信息（姓名、身份证、联系方式）
4. 审核通过后获得买家账号

二、商家入驻流程
1. 商家提交入驻申请（营业执照、法人身份证等）
2. 平台审核商家资质（1-3 个工作日）
3. 审核通过后签署入驻协议
4. 商家上架商品

三、用户下单流程
1. 用户浏览商品
2. 选择商品加入购物车
3. 提交订单，填写收货地址
4. 选择支付方式（微信/支付宝/银行卡）
5. 支付成功后订单生效

四、支付流程
1. 用户选择支付方式
2. 跳转至支付网关
3. 完成支付
4. 平台收到付款通知
5. 商家发货

五、订单管理
1. 用户可查看订单状态（待发货/已发货/已完成）
2. 商家可管理订单（发货/退款/退货）
3. 平台可监控所有交易数据
4. 支持售后申请（退款/退货）

六、结算流程
1. 用户确认收货
2. 平台将款项结算给商家（扣除平台服务费）
3. 商家收到结算款项
```

### 第三方入驻协议要点

- 商家身份认证要求（营业执照、法人身份证）
- 商品上架规范（禁止品类、质量要求）
- 平台服务条款（费率、结算周期）
- 违规处罚规则（虚假商品、欺诈行为的处理）
- 用户隐私保护承诺
- 争议解决方式

## 🗺️ 办理流程

> **所有省份统一入口**：https://ythzxfw.miit.gov.cn

### ① 登录工信部平台
→ 打开 https://ythzxfw.miit.gov.cn → 注册企业账号

### ② 在线申请
→ 首页点击【行政许可】→【电信业务经营许可】→【在线办理】
→ 选择"省内在线办理"
→ 选择"在线数据处理与交易处理业务"（B21 类）

### ③ 填写申请表
→ 逐项填写公司信息和业务描述
→ 业务描述要突出"交易处理"功能

### ④ 上传材料
→ 按清单逐份上传（建议统一用 PDF）
→ 特别注意上传 EDI 特有的交易流程说明

### ⑤ 等待审核
→ 初审：5 个工作日内
→ 审批：约 60 个工作日（约 3 个月）
→ 审核结果会发短信通知

### ⑥ 领取许可证
→ 审核通过后，到通信管理局窗口领取
→ 或选择邮寄（在线申请时勾选）

## ❓ 常见问题

**Q: 自营电商需要 EDI 吗？**
A: 不需要。自营电商用 ICP 备案即可。只有让第三方商家入驻才需要 EDI。

**Q: 跟我自己的商城网站有什么区别？**
A: 如果网站只是自己卖自己的商品，不需要 EDI。如果允许其他商家在您平台上开店，才需要 EDI。

**Q: 可以做跨境电商吗？**
A: EDI 许可证不限制跨境电商，但跨境电商还需要额外资质。

**Q: EDI 和 ICP 可以同时办吗？**
A: 可以。很多平台同时需要 ICP + EDI（既发布信息又有交易）。

**Q: 3 人社保必须是正式员工吗？**
A: 需要有劳动合同 + 社保缴纳证明。实习生/临时工不行。

**Q: 网站需要有什么功能？**
A: 需要有完整的交易功能页面（商品展示、下单、支付、订单管理）。
