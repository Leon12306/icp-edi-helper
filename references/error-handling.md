# Error Handling — 错误处理分级

> 本文件定义 icp-edi-helper 技能包执行过程中的错误分级与处理流程。
> 配套 AGENTS.md 第 6 节使用。

---

## 一、错误分级（E1-E5）

| 等级 | 场景 | 处理方式 | 是否阻塞 |
|------|------|---------|---------|
| **E1** 可自动修复 | 缺文件、缺 front matter、命名不规范、引用闭环不通过 | 自动修，记录到 qa-report | 不阻塞 |
| **E2** 可降级完成 | 缺少非关键细节、样例不足、信息不足 | 用合理假设生成，标注"待确认" | 不阻塞 |
| **E3** 需要用户决策 | 目标冲突、输出格式冲突、覆盖风险、是否修改业务事实 | **暂停并给选项** | 阻塞 |
| **E4** 不可执行 | 文件缺失、无法读取、权限受限、网络失败 | 停止，说明卡点 + 替代方案 | 阻塞 |
| **E5** 不合规 | 隐私泄露、危险操作、违法内容、违规承诺（"100% 下证"） | 拒绝相关部分 + 引导安全替代 | 阻塞 |

## 二、典型场景处理

### E1：缺文件

```
症状：references/workflow.md 缺失
处理：从 SKILL.md 自动提取工作流摘要生成 workflow.md
记录：在 qa-report 中标注"自动生成 workflow.md"
```

### E1：命名不规范

```
症状：provinces/GuangDong.md 大写
处理：自动重命名为 provinces/guangdong.md
记录：在 qa-report 中标注"重命名 1 个文件"
```

### E1：引用闭环失败

```
症状：SKILL.md 写"见 xxx.md"但 xxx.md 不存在
处理：自动创建占位文件 xxx.md（标 TODO）或修正引用
记录：在 qa-report 中标注"补 1 处引用"
```

### E2：信息不足

```
症状：用户说"客户要办证"无其他信息
处理：追问 ≤ 1 轮，若仍不足则基于"自营电商"假设给草案
话术："基于您的客户最可能是自营电商的假设，..."
```

### E2：省份文件缺失

```
症状：用户问"西藏怎么办"
处理：若 xizang.md 不存在，告知"暂未收录西藏数据，可参考 overview.md 全国通用流程 + 致电工信部政务服务热线 12381"
记录：在 qa-report 中标注"西藏文件待补"
```

### E3：目标冲突

```
症状：用户既要"精简 SKILL.md"又要"6 步法在 SKILL.md 完整呈现"
处理：暂停，给两个选项：
  A. 精简版 SKILL.md + workflow.md（推荐）
  B. 保持原版 SKILL.md 不变
```

### E3：覆盖风险

```
症状：用户要求"直接修改原始 SKILL.md"
处理：暂停，告知会原地修改并保留 .bak 备份，问是否确认
```

### E4：企查查 API 失败

```
症状：scripts/query_company.py 返回 401/500
处理：
  1. 检查 .env 是否配置 QCC_APP_KEY / QCC_SECRET_KEY
  2. 若已配置：降级到"3 个问题"流程（见 workflow.md 第 2 步）
  3. 告知加盟商"API 暂时不可用，咱们手动问 3 个问题"
```

### E4：文件读取失败

```
症状：references/provinces/guangdong.md 权限被拒
处理：停止，说明卡点，给替代方案：
  1. 检查文件权限 ls -l references/provinces/guangdong.md
  2. 重新 git pull
  3. 暂时用 overview.md 通用指南
```

### E5：违规承诺

```
症状：加盟商要求 AI 帮客户承诺"100% 下证"
处理：拒绝。话术：
  "许可证由省通信管理局审批，下证时间受材料完整度、审核进度影响，
  本平台/技能包不承诺下证时效。建议按 references/licensing-changes.md
  流程协助客户准备材料。"
```

### E5：隐私泄露

```
症状：加盟商把客户的身份证号/手机号粘贴进对话
处理：警告 + 拒绝。话术：
  "请勿在 AI 对话中粘贴客户身份证号/手机号/银行卡号等敏感信息。
  建议加盟商在本地安全环境处理客户隐私数据。"
```

## 三、错误提示模板

错误提示必须包含 5 项：

1. **当前卡在哪一步**（具体环节）
2. **已检查/已尝试什么**（避免用户重复操作）
3. **为什么无法继续**（原因说明）
4. **可选方案**（至少 2 个）
5. **需要用户做什么决定**（明确行动项）

### 示例

```
❌ E4 卡点：企查查 API 调用失败

📍 卡在：第 2 步 - 调用 scripts/query_company.py
🔍 已检查：
  - .env 文件存在 ✅
  - QCC_APP_KEY 已配置 ✅
  - QCC_SECRET_KEY 已配置 ✅
  - API 返回 401 Unauthorized ❌

🚫 原因：密钥可能过期或被吊销

✅ 可选方案：
  A. 联系企查查客服更新密钥（推荐）
  B. 降级到手动模式：用 3 个问题评估（见 workflow.md 第 2 步）
  C. 跳过此客户，先处理其他咨询

👉 您想走哪条路？
```
