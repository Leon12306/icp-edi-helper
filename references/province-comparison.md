# 31 省差异对照表

> 📌 **AI 调用规则**：本文件**不列电话**（电话在 `provincial-authorities.md`）；只列**省特异差异**，帮客户/加盟商对比各省。

---

## 一、办事流程（基本一致）

**全国统一流程**（详见 `references/overview.md`）：

1. 登录 `ythzxfw.miit.gov.cn` → 注册企业账号
2. 选择"省内许可证"或"跨地区许可证"
3. 选"信息服务业务(仅限互联网信息服务)"= ICP，或 EDI
4. 填表 + 上传材料
5. 初审 5 工作日 + 审查 60 自然日
6. 通过 → 领证（5 年有效）

**绝大多数省完全按这个流程走**，下面是**省特异差异**。

## 二、跨省差异（速查表）

| 省份 | 关键差异 | 影响 |
|------|---------|------|
| **北京** | 审核最严，承诺 40 工作日办结（实际常 30-60 日） | 材料驳回率高，多自查 |
| **上海** | 大量特殊规定：前置审批/年检/变更时限/处罚细则/外资 100% 试点 | 见 `references/provinces/_shanghai-special.md` |
| **广东** | 要公司章程 + 网站截图 + 服务器接入协议；深圳 0755 电话 | 多准备 3 份材料 |
| **湖南** | 申请材料要**仿宋三号字、A4 单面打印** | 格式不合规直接退回 |
| **广西** | 要交**纸质材料原件**到政务中心 | 不能纯线上 |
| **河北** | 扫描件：≤5MB，>10 张图片打包 word/pdf | 提前压缩 |
| **山东** | 材料全部指向 `tsm.miit.gov.cn` 系统，不在通信管理局页 | 办前先去系统注册 |
| **浙江** | 外资 100% 试点（2024-10）；办理入口：浙江政务服务网 + 工信部平台（双入口） | 外资企业友好 |
| **海南** | 外资 100% 试点（2024-10 起） | 外资企业友好 |
| **陕西** | 5 日内一次性告知补正；60 日内审查完毕 | 时限明确 |
| **山西** | 支持**邮寄取证** | 不用跑现场 |
| **辽宁** | 隐瞒情况或虚假材料：**1 年内**不得再申请 | 严格 |
| **福建** | 厦门 0592 独立电话 | 厦门企业用本地号 |
| **河南** | 官网动态加载，无独立指南页 | 走工信部平台 |
| **四川** | 官网未挂独立指南页 | 走工信部平台 |
| **重庆** | 官网仅"渝快办"跳转 | 走工信部平台 |
| **青海** | 官网为"经营许可/码号/互联网管理"3 业务总览 | 走工信部平台 |
| **天津** | 源页未列审查时限 | 走工信部平台（法定 60 日） |
| **西藏** | 源页未列审查时限 | 走工信部平台（法定 60 日） |
| **广东** | 源页无咨询电话 | 用本表电话 |
| **海南/新疆** | 源页未列材料清单（引 42 号令） | 用 `references/overview.md` 材料 |

## 三、外资 100% 试点 4 城市

| 城市 | 政策时间 | 业务范围 | 备注 |
|------|---------|---------|------|
| **北京** | 2024-10 | ICP/EDI | 外资可达 100% |
| **上海** | 2021 | ICP/EDI | 最早试点 |
| **浙江**（含杭州） | 2024-10 | ICP/EDI | 全省 |
| **海南** | 2024-10 | ICP/EDI | 全省 |

> 其他省份有外资需走额外审批流程，不可达 100%。

## 四、社保要求

| 类型 | 省份 |
|------|------|
| 1 个月社保即可 | 大多数省（北京/广东/上海等） |
| 3 个月连续社保 | 部分省（具体看各省工信部页） |

> **统一兜底**：按 3 个月准备更稳妥。

---

## 五、注册资本

| 业务范围 | 要求 |
|---------|------|
| 省内（单省） | **≥ 100 万元**（认缴即可） |
| 跨地区（全国） | **≥ 1000 万元**（认缴即可） |

---

## 六、办理周期

| 阶段 | 时限 |
|------|------|
| 初审 | 5 个工作日内 |
| 受理 | 15 日内（部分省） |
| 审查 | 60 自然日内（法定） |
| 北京（特严） | 承诺 40 工作日办结 |
| 总计 | 约 60-90 日 |

---

## 七、有效期 & 续期

| 项目 | 要求 |
|------|------|
| 有效期 | **5 年** |
| 续期申请 | 到期前 **90 日** |
| 变更申请 | 决定/工商变更后 **30 日内** |
| 注销申请 | 决定后 **30 日内** |
